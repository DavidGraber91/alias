# אליאס

משחק מילים לקבוצות, על טלפון אחד. עברית בלבד.
האפליקציה כתובה ב-HTML, CSS ו-JavaScript רגיל, בלי תלויות ובלי שלב build.

## הרצה מקומית

```
python -m http.server 8000
```

(או `npm start`). אחר כך פותחים `http://localhost:8000`.

חשוב: לא פותחים את `index.html` ישירות מהקובץ. הדפדפן חוסם טעינת קבצי JSON מכתובת `file://`.

לבדיקה בטלפון באותה רשת Wi-Fi, פותחים בטלפון את כתובת ה-IP של המחשב עם `:8000`.

בדיקות ללוגיקה (נדרש Node 18 ומעלה):

```
node --test
```

## העלאה ושיתוף עם GitHub Pages

1. יוצרים מאגר חדש ב-GitHub ודוחפים אליו את כל הקבצים.
2. ב-GitHub: **Settings ← Pages ← Build and deployment**, בוחרים **Deploy from a branch**, ענף `main` ותיקייה `/ (root)`.
3. אחרי דקה או שתיים המשחק זמין בכתובת `https://<שם-משתמש>.github.io/<שם-המאגר>/`.

את הקישור אפשר לשלוח כמו שהוא. כפתור "שתפו את המשחק" במסך הבית משתף את הכתובת הנוכחית.

## הוספת רמות ומילים

הרמות מוגדרות ב-`levels.json`, והמסך של ההגדרות נבנה מהקובץ הזה:

```json
{ "id": 6, "name": "ספורט", "description": "משחקים וספורטאים", "icon": "⚽" }
```

כל מילה ב-`words.json` מפנה לרמה לפי ה-`id`:

```json
{ "word": "שער", "level": 6 }
```

- מספר המילים שליד כל רמה במסך ההגדרות מחושב אוטומטית.
- רמה בלי מילים מוצגת כמושבתת.
- אפשר להוסיף כמה רמות שרוצים, ולשנות שמות, תיאורים ואייקונים בלי לגעת בקוד.

## חוקי המשחק

- 2–6 קבוצות. בכל תור קבוצה אחת משחקת, ומי שמחזיק את הטלפון מסביר מילים.
- **נכון** נותן נקודה. **אסור** מוריד נקודה. **דלג** מוריד נקודה, לא מוריד, או לא אפשרי, לפי ההגדרות.
- **הזדמנות אחרונה:** כשהזמן נגמר, המילה שעל המסך נשארת וכל הקבוצות יכולות לנחש. מי שניחשה מקבלת נקודה (או שתיים, אם הוגדר כך לקבוצה שאינה המסבירה). הקבוצה המסבירה לא מקבלת ולא מפסידה על המילה הזו כשקבוצה אחרת ניחשה.
- המשחק נגמר אחרי מספר סיבובים קבוע. בתיקו בראש הקבוצות שבתיקו משחקות תור הכרעה אחד.
- בסיכום כל תור אפשר ללחוץ על מילה כדי לתקן את התוצאה שלה.
- משחק שנקטע נשמר ב-`localStorage`, וחוזרים אליו מדף הבית ("המשך משחק"). אם הדף נסגר באמצע תור, חוזרים להכנה לאותו תור.

## מה עוד לא נעשה

- התקנה למסך הבית ועבודה בלי אינטרנט (PWA: `manifest.json` ו-`sw.js`).
- קוד QR לשיתוף.
- מאגר מילים גדול. כרגע יש 25 מילים בכל רמה, רק כדי שיהיה אפשר לשחק.
