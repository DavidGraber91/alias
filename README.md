# אליאס (מהדורת סטלה)

משחק מילים לקבוצות, מכמה טלפונים. עברית בלבד.
האפליקציה כתובה ב-HTML, CSS ו-JavaScript רגיל, בלי תלויות ובלי שלב build.

## איך משחקים בין כמה טלפונים

1. טלפון אחד לוחץ "משחק חדש", מגדיר ומתחיל. נוצר חדר עם קוד של 6 ספרות (אפשר גם לשתף קישור).
2. שאר הטלפונים מזינים את הקוד בדף הבית ("יש לכם קוד משחק?"), או פותחים את הקישור. אין חובה שכולם יתחברו, ואפשר להצטרף ולעזוב באמצע.
3. אין תור קבוע בין הטלפונים. בשלב ההכנה כל טלפון יכול ללחוץ "אני מסביר/ה". הראשון שלוחץ הוא המסביר/ה: **רק אצלו מוצגות המילים** והוא מסמן נכון, דלג ואסור.
4. בשאר הטלפונים רואים את הטיימר ואת המילים שכבר קיבלו תוצאה (✓ נכון, ✗ אסור, דילוג), בלי המילה הנוכחית.
5. בסוף התור המסביר/ה בודק/ת את הסיכום ומאשר/ת, וכולם חוזרים להכנה לתור הבא.
6. אם הטלפון המסביר/ה כבה או נסגר, בכל טלפון אחר יש "הטלפון המסביר/ה לא מגיב?" ← "אני לוקח/ת את השליטה". אם הוא נעלם בזמן שהטיימר רץ, טלפון אחר גם סוגר את התור אוטומטית אחרי 3 שניות.

### חיבור בין טלפונים אמיתיים (Firebase)

בלי הגדרות המשחק עובד במצב מקומי: כמה לשוניות באותו דפדפן מדברות זו עם זו דרך `localStorage`. זה טוב לבדיקה, לא למשחק אמיתי.

1. ב-[Firebase console](https://console.firebase.google.com) יוצרים פרויקט, ואז **Build ← Realtime Database ← Create database**.
2. בלשונית **Rules** מדביקים את התוכן של `database.rules.json` ולוחצים Publish.
3. ב-**Project settings ← Your apps** יוצרים Web app ומעתיקים את אובייקט ההגדרות.
4. מדביקים אותו ב-`firebase-config.js` במקום `null`, ודוחפים ל-GitHub Pages.

הערות:
- ערכי ההגדרות ב-`firebase-config.js` אינם סודיים. ההגנה היא הכללים: אי אפשר לרשום את כל החדרים, רק לקרוא או לכתוב חדר שמכירים את הקוד שלו, ורק במבנה הצפוי.
- מי שמנחש קוד בן 6 ספרות יכול להיכנס לחדר. זה מתאים למשחק חברים. אם צריך יותר, מוסיפים Firebase Anonymous Auth.
- החדרים נשארים במסד. מדי פעם אפשר למחוק את `rooms` ב-console.
- ספריית Firebase נטענת מ-`gstatic.com` בגרסה קבועה. לא הוספתי `integrity` כי אי אפשר לשים אותו על `import()` רגיל. אם חשוב לכם, אפשר להוסיף import map עם שדה `integrity`.

## הרצה מקומית

```
python -m http.server 8000
```

(או `npm start`). אחר כך פותחים `http://localhost:8000`.

חשוב: לא פותחים את `index.html` ישירות מהקובץ. הדפדפן חוסם טעינת קבצי JSON מכתובת `file://`.

לבדיקה בטלפון באותה רשת Wi-Fi, פותחים בטלפון את כתובת ה-IP של המחשב עם `:8000`.

בדיקות ללוגיקה (נדרש Node 18 ומעלה):

```
node --test
```

## העלאה ושיתוף עם GitHub Pages

1. יוצרים מאגר חדש ב-GitHub ודוחפים אליו את כל הקבצים.
2. ב-GitHub: **Settings ← Pages ← Build and deployment**, בוחרים **Deploy from a branch**, ענף `main` ותיקייה `/ (root)`.
3. אחרי דקה או שתיים המשחק זמין בכתובת `https://<שם-משתמש>.github.io/<שם-המאגר>/`.

את הקישור אפשר לשלוח כמו שהוא. כפתור "שתפו את המשחק" במסך הבית משתף את הכתובת הנוכחית.

## הוספת רמות ומילים

הרמות מוגדרות ב-`levels.json`, והמסך של ההגדרות נבנה מהקובץ הזה:

```json
{ "id": 6, "name": "ספורט", "description": "משחקים וספורטאים", "icon": "⚽" }
```

כל מילה ב-`words.json` מפנה לרמה לפי ה-`id`:

```json
{ "word": "שער", "level": 6 }
```

- מספר המילים שליד כל רמה במסך ההגדרות מחושב אוטומטית.
- רמה בלי מילים מוצגת כמושבתת.
- אפשר להוסיף כמה רמות שרוצים, ולשנות שמות, תיאורים ואייקונים בלי לגעת בקוד.

| `tests/game.test.js`, `tests/room.test.js` | בדיקות ללוגיקה ולפעולות החדר |

## חוקי המשחק

- 2–6 קבוצות. בכל תור קבוצה אחת משחקת, ומי שמחזיק את הטלפון מסביר מילים.
- **נכון** נותן נקודה. **אסור** מוריד נקודה. **דלג** מוריד נקודה, לא מוריד, או לא אפשרי, לפי ההגדרות.
- **הזדמנות אחרונה:** כשהזמן נגמר, המילה שעל המסך נשארת וכל הקבוצות יכולות לנחש. מי שניחשה מקבלת נקודה (או שתיים, אם הוגדר כך לקבוצה שאינה המסבירה). הקבוצה המסבירה לא מקבלת ולא מפסידה על המילה הזו כשקבוצה אחרת ניחשה.
- המשחק נגמר אחרי מספר סיבובים קבוע. בתיקו בראש הקבוצות שבתיקו משחקות תור הכרעה אחד.
- בסיכום כל תור אפשר ללחוץ על מילה כדי לתקן את התוצאה שלה.
- המשחק שמור בחדר המשותף, לא בטלפון. רענון דף חוזר לאותו חדר אוטומטית (ולמסביר/ה הוא נשאר מסביר/ה). לשונית שנסגרה לגמרי חוזרת עם הקוד או הקישור.

## מה עוד לא נעשה

- התקנה למסך הבית ועבודה בלי אינטרנט (PWA: `manifest.json` ו-`sw.js`).
- קוד QR לשיתוף.
- מאגר מילים גדול. כרגע יש 25 מילים בכל רמה, רק כדי שיהיה אפשר לשחק.
